Android Setup (ADB)

                  

                    Only needed for testing Android devices or emulators.
                  

                

                Checking
              

              

                

                  

                    

                      1. Install Android Platform Tools (adb)
                    

                    

                      Download Android SDK Platform Tools and add the
                      platform-tools folder to your system PATH (or
                      install via Android Studio).
                    

                  

                

                

                  

                    

                      2. Enable USB Debugging (or start an Emulator)
                    

                    

                      On a phone: Settings → About phone → tap
                      Build number several times until
                      Developer options unlocks → enable
                      USB debugging, then connect via USB and
                      tap Allow.
